## 运行
```bash
nvm use                # 在项目根目录执行，读取 .nvmrc 切到 Node 24
cd exercises
npx vitest W1D1        # 监听模式，保存文件自动重跑
```
起始状态下 6 个测试中 5 个失败，做完全部变绿即可。
ex2 的"不修改 players"测试一开始就是绿的，它用来拦截原地 `sort` 的写法，做完后要确认它仍然是绿的。每道题做完后，用一句话写下"为什么原来的写法不对"。
